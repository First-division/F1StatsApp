# F1 Stats App

A small React Native app built with Expo and Expo Router v6 for Expo Go.

## Stack

- React Native
- Expo SDK 54
- Expo Router v6
- TypeScript

## Run locally

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the Expo development server:

   ```bash
   npm start
   ```

3. Open the project in Expo Go by scanning the QR code from the terminal or browser.

## Available scripts

- `npm start`
- `npm run android`
- `npm run ios`
- `npm run web`
- `npm run typecheck`
